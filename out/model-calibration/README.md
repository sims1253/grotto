# Phase 4 model-calibration experiment output

**NON-CANDIDATE.** Everything here is a Phase 4 calibration experiment. No
palette is final (DESIGN.md section 1). The point is to test whether a
systematic environmental transform can reproduce a designer's intent across
day / evening / night, and where it needs hand correction.

## How to regenerate (reproducible)

```bash
# Build the systematic family + derivation report (JSON/YAML/text/HTML)
uv run grotto family spec/bindings/calibration.yaml --out out/model-calibration

# Systematic-vs-hand-tuned comparison report (JSON/YAML/text/HTML)
uv run grotto compare-families spec/bindings/calibration.yaml \
    themes/experiments/handtuned-day.yaml \
    themes/experiments/handtuned-evening.yaml \
    themes/experiments/handtuned-night.yaml \
    --out out/model-calibration
```

Identical inputs produce byte-identical output (no wall-clock timestamp); an
input hash is embedded for provenance.

## Files

| file | what |
|---|---|
| `calibration.build.{json,yaml,txt,html}` | the systematic family build: per-role derivation provenance (requested/capped/realized OKLCH, independent cap+gamut losses, winning constraint, conflicts), the corrected cross-variant stability report, issues. |
| `calibration.compare.{json,yaml,txt,html}` | systematic vs hand-tuned: per-role dE_OK deltas and the headline finding -- whether the systematic output needed hand adjustment, and where. |

## The headline finding

The systematic transform reproduces the hand-tuned closely, but a designer
corrected a handful of roles -- exactly the places DESIGN.md section 9 predicts
the transform to be weakest: backgrounds / near-background surfaces and the
blue/violet region (R-8). See `calibration.compare.txt` for the exact list and
the comparison HTML for side-by-side swatches.

## Inputs (all NON-CANDIDATE)

- `spec/bindings/calibration.yaml` -- semantic hue anchors + scales + bounded
  rationale-bearing adjustments (the binding, not a palette).
- `themes/experiments/handtuned-*.yaml` -- hand-tuned comparison target,
  generated by `scripts/gen_handtuned.py` as curated designer corrections over
  the systematic output.

## Caveats

- APCA is independent work in progress, not a W3C Recommendation or current
  WCAG criterion.
- WCAG overrides the Night foreground ceiling and the APCA preference; each
  override is recorded in the derivation trace.
- Cap/gamut losses are reported independently; silent clipping is prohibited
  (DESIGN.md section 5).
- Ink-on-surface legibility is evaluated as issues, never raised.
